# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

## Данные

В приложении используются два основных типа данных, описывающих товар и покупателя.

Товар:
```ts
interface IProduct {
  id: string;
  description: string;
  image: string;
  title: string;
  category: string;
  price: number | null;
}
```
Интерфейс описывает карточку товара, которая приходит с сервера и отображается в каталоге, модальном окне подробностей и корзине. Поле `price` может быть `null`, если товар "бесценный" и его нельзя купить.

Покупатель:
```ts
interface IBuyer {
  payment: TPayment;
  email: string;
  phone: string;
  address: string;
}
```
Интерфейс описывает данные, которые покупатель вводит при оформлении заказа: способ оплаты, адрес доставки и контактные данные для связи.

## Модели данных

#### Класс Catalog
Отвечает за хранение и работу с массивом товаров, полученных с сервера, а также за хранение товара, выбранного для подробного просмотра.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий для уведомления об изменениях данных.

Поля класса:  
`items: IProduct[]` - массив всех товаров, полученных с сервера.  
`selectedItem: IProduct | null` - товар, выбранный пользователем для подробного отображения в модальном окне.  
`events: IEvents` - брокер событий.

Методы класса:  
`setItems(items: IProduct[]): void` - сохраняет переданный массив товаров в поле `items`, генерирует событие `catalog:changed`.  
`getItems(): IProduct[]` - возвращает массив всех товаров.  
`getItem(id: string): IProduct | undefined` - возвращает товар по его `id` либо `undefined`, если товар не найден.  
`setSelectedItem(item: IProduct): void` - сохраняет товар в поле `selectedItem`, генерирует событие `catalog:selectedItemChanged`.  
`getSelectedItem(): IProduct | null` - возвращает товар, выбранный для подробного отображения.

#### Класс Basket
Отвечает за хранение товаров, которые пользователь выбрал для покупки.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий для уведомления об изменениях данных.

Поля класса:  
`items: IProduct[]` - массив товаров, добавленных пользователем в корзину.  
`events: IEvents` - брокер событий.

Методы класса:  
`getItems(): IProduct[]` - возвращает массив товаров, находящихся в корзине.  
`addItem(item: IProduct): void` - добавляет переданный товар в массив корзины, генерирует событие `basket:changed`.  
`removeItem(id: string): void` - удаляет из корзины товар с переданным `id`, генерирует событие `basket:changed`.  
`clear(): void` - очищает корзину, генерирует событие `basket:changed`.  
`getTotal(): number` - возвращает суммарную стоимость всех товаров в корзине.  
`getCount(): number` - возвращает количество товаров в корзине.  
`hasItem(id: string): boolean` - проверяет, находится ли товар с переданным `id` в корзине.

#### Класс Buyer
Отвечает за хранение и валидацию данных покупателя, необходимых для оформления заказа.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий для уведомления об изменениях данных.

Поля класса:  
`payment: TPayment | ''` - выбранный способ оплаты; пустая строка означает, что способ оплаты ещё не выбран.  
`email: string` - email покупателя.  
`phone: string` - телефон покупателя.  
`address: string` - адрес доставки.  
`events: IEvents` - брокер событий.

Методы класса:  
`setData(data: Partial<IBuyer>): void` - сохраняет переданные данные в соответствующие поля, не затрагивая остальные, генерирует событие `buyer:changed`.  
`getData(): IBuyer` - возвращает объект со всеми данными покупателя.  
`clear(): void` - очищает все поля класса, генерирует событие `buyer:changed`.  
`validate(): FormErrors` - проверяет валидность всех полей (поле валидно, если оно не пустое) и возвращает объект с ошибками по невалидным полям.

## Слой коммуникации

#### Класс ProductsApi
Отвечает за взаимодействие с сервером: получение каталога товаров и отправку данных заказа. Использует композицию — принимает в конструктор объект, реализующий интерфейс `IApi`, и делегирует ему выполнение запросов.

Конструктор:  
`constructor(api: IApi)` - принимает объект, реализующий интерфейс `IApi`, через который будут выполняться запросы.

Поля класса:  
`api: IApi` - объект для выполнения HTTP-запросов.

Методы класса:  
`getProducts(): Promise<IProductsResponse>` - выполняет GET-запрос на эндпоинт `/product/` и возвращает промис с объектом, содержащим массив товаров.  
`postOrder(order: IOrder): Promise<IOrderResult>` - выполняет POST-запрос на эндпоинт `/order/`, передавая данные заказа, и возвращает промис с объектом, подтверждающим оформление заказа.

## Представление (View)

#### Класс Card<T>
Абстрактный родитель для всех карточек товара. Хранит общие для всех карточек элементы разметки и методы их изменения.

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - принимает корневой DOM-элемент карточки и брокер событий.

Поля класса:  
`events: IEvents` - брокер событий для уведомления о действиях пользователя.  
`cardId: string` - идентификатор товара, необходим для формирования события с указанием, какой товар был выбран.  
`titleElement: HTMLElement` - элемент заголовка карточки.  
`priceElement: HTMLElement` - элемент цены карточки.

Методы класса:  
`set id(value: string)` - сохраняет идентификатор товара.  
`set title(value: string)` - устанавливает текст заголовка.  
`set price(value: number | null)` - устанавливает текст цены; если `value === null`, выводит «Бесценно».

#### Класс CatalogCard extends Card<ICatalogCardData>
Отвечает за карточку товара в каталоге на главной странице (шаблон `card-catalog`).

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит в разметке элементы изображения и категории, устанавливает слушатель клика на контейнер.

Поля класса:  
`imageElement: HTMLImageElement` - элемент изображения товара.  
`categoryElement: HTMLElement` - элемент категории товара.

Методы класса:  
`set image(value: string)` - устанавливает `src` изображения, формируя полную ссылку через `CDN_URL`.  
`set category(value: string)` - устанавливает текст категории и CSS-модификатор фона по словарю `categoryMap`.

При клике на карточку генерируется событие `card:select` с данными `{ id: string }`.

#### Класс PreviewCard extends Card<IPreviewCardData>
Отвечает за карточку с подробной информацией о товаре в модальном окне (шаблон `card-preview`).

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит элементы изображения, категории, описания и кнопки, устанавливает слушатель клика на кнопку.

Поля класса:  
`imageElement: HTMLImageElement` - изображение товара.  
`categoryElement: HTMLElement` - категория товара.  
`descriptionElement: HTMLElement` - описание товара.  
`buttonElement: HTMLButtonElement` - кнопка добавления/удаления товара.

Методы класса:  
`set image(value: string)` - устанавливает изображение, формируя полную ссылку через `CDN_URL`.  
`set category(value: string)` - устанавливает категорию с модификатором.  
`set description(value: string)` - устанавливает текст описания.  
`set buttonText(value: string)` - устанавливает текст кнопки. Текст («Купить» / «Удалить из корзины» / «Недоступно») формируется Презентером и передаётся готовым.  
`set buttonDisabled(value: boolean)` - блокирует/разблокирует кнопку.

При клике на кнопку генерируется событие `card:toggleBasket` с данными `{ id: string }`.

#### Класс BasketCard extends Card<IBasketCardData>
Отвечает за строку товара внутри списка корзины (шаблон `card-basket`).

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит элемент порядкового номера и кнопку удаления, устанавливает слушатель клика на кнопку.

Поля класса:  
`indexElement: HTMLElement` - элемент порядкового номера товара в списке.  
`deleteButton: HTMLButtonElement` - кнопка удаления товара из корзины.

Методы класса:  
`set index(value: number)` - устанавливает порядковый номер.

При клике на кнопку удаления генерируется событие `basket:remove` с данными `{ id: string }`.

#### Класс Gallery
Отвечает за отображение каталога товаров на главной странице (элемент `.gallery`).

Конструктор:  
`constructor(container: HTMLElement)` - принимает корневой элемент `.gallery`.

Методы класса:  
`set items(value: HTMLElement[])` - заменяет содержимое контейнера переданным массивом разметки карточек.

#### Класс Header
Отвечает за шапку сайта — кнопку и счётчик корзины.

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит кнопку и счётчик корзины, устанавливает слушатель клика на кнопку.

Поля класса:  
`basketButton: HTMLButtonElement` - кнопка открытия корзины.  
`basketCounter: HTMLElement` - счётчик товаров в корзине.

Методы класса:  
`set counter(value: number)` - устанавливает текст счётчика.

При клике на кнопку генерируется событие `basket:open`.

#### Класс Modal
Отвечает за отображение модального окна. Не имеет и не может иметь дочерних классов — весь контент модалки передаётся в неё как самостоятельный DOM-элемент.

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит кнопку закрытия и контейнер контента, устанавливает слушатели клика на кнопку закрытия и на оверлей (клик вне `.modal__container`).

Поля класса:  
`closeButton: HTMLButtonElement` - кнопка закрытия модального окна.  
`contentElement: HTMLElement` - контейнер, в который вставляется содержимое.

Методы класса:  
`set content(value: HTMLElement)` - вставляет переданный элемент в контейнер контента.  
`open(): void` - добавляет модификатор `modal_active` контейнеру.  
`close(): void` - удаляет модификатор `modal_active` и очищает содержимое.

При клике на крестик или на область вне окна генерируется событие `modal:close`.

#### Класс Success
Отвечает за содержимое модального окна успешного оформления заказа (шаблон `success`).

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит кнопку закрытия и элемент описания, устанавливает слушатель клика на кнопку.

Поля класса:  
`closeButton: HTMLButtonElement` - кнопка «За новыми покупками!».  
`descriptionElement: HTMLElement` - элемент с текстом о списанной сумме.

Методы класса:  
`set total(value: number)` - устанавливает текст «Списано {value} синапсов».

При клике на кнопку генерируется событие `modal:close`.

#### Класс Basket
Отвечает за содержимое модального окна корзины (шаблон `basket`).

Конструктор:  
`constructor(container: HTMLElement, events: IEvents)` - находит список товаров, элемент суммы и кнопку оформления, устанавливает слушатель клика на кнопку.

Поля класса:  
`listElement: HTMLElement` - контейнер `<ul>` для товаров.  
`priceElement: HTMLElement` - элемент общей суммы.  
`button: HTMLButtonElement` - кнопка «Оформить».

Методы класса:  
`set items(value: HTMLElement[])` - заменяет содержимое списка; если массив пуст, выводит текст «Корзина пуста» вместо списка и блокирует кнопку оформления.  
`set total(value: number)` - устанавливает текст суммы.

При клике на кнопку «Оформить» генерируется событие `order:open`.

#### Класс Form<T>
Абстрактный родитель для форм оформления заказа. Хранит общие элементы: кнопку отправки и блок ошибок, обрабатывает ввод данных и отправку формы.

Конструктор:  
`constructor(container: HTMLFormElement, events: IEvents)` - принимает форму, находит кнопку отправки и блок ошибок; устанавливает слушатель `input` на форму (для каждого поля генерирует событие изменения) и слушатель `submit` (с `preventDefault`, генерирует событие отправки).

Поля класса:  
`events: IEvents` - брокер событий.  
`formName: string` - имя формы, полученное из атрибута `name`, используется для формирования названий событий.  
`submitButton: HTMLButtonElement` - кнопка отправки формы.  
`errorsElement: HTMLElement` - элемент для вывода текста ошибки.

Методы класса:  
`set valid(value: boolean)` - блокирует/разблокирует кнопку отправки.  
`set errors(value: string)` - устанавливает текст ошибки.

При изменении значения любого поля генерируется событие `{название формы}.{имя поля}:change` с данными `{ value: string }` (например, `order.address:change`). При отправке формы генерируется событие `{название формы}:submit` (например, `order:submit`).

#### Класс Order extends Form<IOrderFormData>
Отвечает за первую форму оформления заказа — выбор способа оплаты и адрес (шаблон `order`).

Конструктор:  
`constructor(container: HTMLFormElement, events: IEvents)` - находит кнопки способов оплаты, устанавливает слушатели клика на каждую.

Поля класса:  
`cardButton: HTMLButtonElement` - кнопка оплаты «Онлайн».  
`cashButton: HTMLButtonElement` - кнопка оплаты «При получении».

Методы класса:  
`set payment(value: TPayment | '')` - выделяет модификатором `button_alt-active` кнопку, соответствующую переданному значению, и снимает модификатор с другой.

При клике на кнопку способа оплаты генерируется событие `order.payment:change` с данными `{ value: TPayment }`.

#### Класс Contacts extends Form<IFormData>
Отвечает за вторую форму оформления заказа — email и телефон (шаблон `contacts`).

Дополнительных полей и методов, кроме унаследованных от `Form`, не требует — поля email и телефон обрабатываются общим слушателем `input` из родительского класса.

## События

Модели данных:  
`catalog:changed` - каталог товаров изменился (после `setItems`).  
`catalog:selectedItemChanged` - изменился товар, выбранный для подробного просмотра (после `setSelectedItem`).  
`basket:changed` - изменилось содержимое корзины (после `addItem`, `removeItem`, `clear`).  
`buyer:changed` - изменились данные покупателя (после `setData`, `clear`).

Представления:  
`card:select` - пользователь выбрал карточку товара в каталоге.  
`card:toggleBasket` - пользователь нажал кнопку добавления/удаления товара в превью.  
`basket:remove` - пользователь нажал кнопку удаления товара из списка в корзине.  
`basket:open` - пользователь нажал на иконку корзины в шапке.  
`order:open` - пользователь нажал кнопку «Оформить» в корзине.  
`order.payment:change` - пользователь выбрал способ оплаты.  
`order.address:change` - пользователь изменил адрес доставки.  
`order:submit` - пользователь нажал «Далее» на первой форме заказа.  
`contacts.email:change` - пользователь изменил email.  
`contacts.phone:change` - пользователь изменил телефон.  
`contacts:submit` - пользователь нажал «Оплатить» на второй форме заказа.  
`modal:close` - пользователь закрыл модальное окно (крестик, клик вне окна или кнопка в окне успеха).
